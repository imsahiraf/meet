# Software Requirements Specification (SRS)

# Chapter 3 - Contacts & Social Graph

---

# Module Overview

The Contacts Module is responsible for discovering users, managing relationships, searching users, maintaining favorites, blocked contacts, invitations, and preparing the communication layer for Chat, Voice Calls, Video Calls, and Meetings.

This module must remain independent so future integrations (Google Contacts, Outlook, LDAP, Microsoft Entra ID, etc.) can be added without changing the core architecture.

---

# FR-021 - Contact Discovery

## Purpose

Allow users to discover other registered users.

---

## Actor

Authenticated User

---

## Priority

Critical

---

## Discovery Methods

The system shall support:

* Phone Number Search
* Email Search
* Username Search
* Display Name Search (Configurable)
* QR Code (Future)
* Contact Sync (Future)

---

## Business Rules

* Only active users shall appear.
* Suspended users shall not appear.
* Blocked users shall follow privacy policies.
* Search results must respect profile visibility.

---

## Database Tables

* users
* user_profiles
* user_privacy_settings

---

## Acceptance Criteria

* Search returns valid users.
* Results respect privacy settings.

---

# Chapter Summary

This chapter establishes the complete social relationship layer of the application. It provides contact discovery, relationship management, presence tracking, favorites, blocking, muting, invitations, and activity summaries, all while respecting user privacy settings. These capabilities serve as the foundation for the Chat, Voice Call, Video Call, Meeting, and Notification modules.
