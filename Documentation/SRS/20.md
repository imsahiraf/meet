# Software Requirements Specification (SRS)

# Chapter 20 - One View Media Engine

---

# Module Overview

The One View Media Engine provides secure, single-view media sharing similar to modern messaging platforms while introducing the Meet platform's unique **Super Access** capability.

This module integrates with:

* Chat Engine
* Group Chat Engine
* File Storage Engine
* Security Engine
* Notification Engine
* Admin Panel
* Audit Engine

Media shall be stored securely and processed according to configurable retention policies.

---

# FR-331 - One View Media

## Purpose

Allow users to send media that can normally be viewed only once.

---

## Supported Media

* Images
* Videos

Future:

* Documents
* Audio

---

## Workflow

1. User selects media.
2. User enables **One View**.
3. Media uploads successfully.
4. Recipient receives the media.
5. Recipient opens the media.
6. View event recorded.
7. Media becomes unavailable after the configured policy is applied.

---

## Acceptance Criteria

Media behaves as a one-view item for standard users.

---

# FR-334 - Automatic Expiration

## Purpose

Remove One View media after it has been consumed.

---

## Administrator Configurable

* Immediate Removal
* Delayed Cleanup
* Scheduled Cleanup

---

## Business Rules

Cleanup shall be performed through Laravel Scheduler.

---

# FR-335 - Super Access

## Purpose

Provide special handling for authorized users.

---

## Authorized Users

Only users explicitly granted the **Super Access** permission by an administrator.

---

## Workflow

1. Authorized user opens One View media.
2. Media is downloaded automatically before display.
3. Media opens normally.
4. Download event recorded.
5. View event recorded.

---

## Business Rules

The media remains governed by retention policies even after automatic download behavior is applied.

---

# Chapter Summary

The One View Media Engine provides secure, single-view media sharing with configurable lifecycle management, automatic cleanup, detailed auditing, and administrative controls. It also introduces the Meet platform's unique **Super Access** capability, allowing specifically authorized users to automatically download One View media before viewing while maintaining full logging and retention controls. The architecture is secure, configurable, and designed for future enhancements without major structural changes.
