# Software Requirements Specification (SRS)

# Chapter 5 - Media & File Sharing Engine

---

# Module Overview

The Media & File Sharing Engine provides secure, scalable, and configurable file transfer capabilities across the Meet platform.

This module is shared by:

* Private Chat
* Group Chat
* Meetings
* Guest Meetings (restricted)
* Future Team Workspaces

The engine must support very large files through chunked uploads while remaining fully compatible with Laravel on standard cPanel hosting.

# FR-056 - Chunk Upload Engine

## Purpose

Support uploading large files without timeout.

---

## Features

* Chunk Upload
* Chunk Resume
* Upload Progress
* Retry Failed Chunk
* Automatic Merge
* Upload Verification

---

## Business Rules

* Chunk size configurable.
* Maximum upload size configurable.
* Temporary chunks automatically cleaned.
* Corrupted uploads automatically discarded.

---

## Database Tables

* uploads
* upload_chunks

---

## Acceptance Criteria

Large files upload successfully without requiring PHP execution time increases beyond reasonable server limits.

---

# FR-057 - Resume Upload

## Purpose

Resume interrupted uploads.

---

## Workflow

1. Upload interrupted.
2. Remaining chunks identified.
3. Upload resumes automatically.
4. File assembled after final chunk.

---

## Acceptance Criteria

Previously uploaded chunks are reused.

# FR-061 - One View Media

## Purpose

Provide WhatsApp-style one-time media.

---

## Supported Types

* Images
* Videos

---

## Workflow

1. Sender selects One View.
2. Recipient opens media.
3. Media becomes unavailable after successful viewing.
4. Cleanup process removes the media according to configured retention rules.

---

## Super Access Mode

If recipient has Super Access permission:

* Media downloads automatically before opening.
* Download is recorded.
* Viewing event recorded.

---

## Database Tables

* one_view_files
* one_view_logs

## Chapter Summary

This chapter defines the complete Media & File Sharing Engine for Meet. It includes chunked uploads, secure storage, previews, downloads, voice notes, one-view media, quotas, analytics, retention policies, and future-ready storage abstraction. The engine is designed to support both current Laravel cPanel deployments and future cloud storage providers without architectural changes.
