# Software Requirements Specification (SRS)

# Chapter 2 - User Profile & Account Management

---

# FR-011 - User Profile

## Purpose

Allow authenticated users to create and manage their personal profile.

---

## Actor

Authenticated User

---

## Priority

Critical

---

## Features

The user shall be able to:

* Upload profile picture
* Change profile picture
* Remove profile picture
* Update full name
* Update username (optional)
* Update phone number (future verification ready)
* Update email address (requires verification)
* Update date of birth
* Update gender (optional)
* Update bio/about
* Update timezone
* Update preferred language
* Update country
* Update profile visibility

---

## Business Rules

* Email change requires Email OTP verification.
* Profile photo must be optimized automatically.
* Maximum profile image size is configurable.
* Supported image formats are configurable.
* Username must be unique if enabled.
* Reserved usernames cannot be used.

---

## Validation Rules

### Name

* Required
* Minimum 2 characters
* Maximum 100 characters

### Bio

* Maximum length configurable
* HTML not allowed
* XSS filtering required

### Avatar

* JPG
* PNG
* WEBP
* Configurable maximum size

---

## Database Tables

* users
* user_profiles
* activity_logs

---

## Acceptance Criteria

* Profile updates successfully.
* Changes appear immediately.
* Activity is logged.

# FR-013 - Change Password

## Purpose

Allow users to change their account password.

---

## Workflow

1. Enter current password.
2. Enter new password.
3. Confirm new password.
4. Validate.
5. Save.
6. Invalidate configured sessions if enabled.

---

## Validation Rules

* Current password required.
* New password cannot match current password.
* Password policy configurable.

---

## Security

* Password hashed using Laravel Hash.
* Password history support (future).
* Rate limiting.

---

## Acceptance Criteria

Password updated successfully.

# FR-020 - Report User

---

## Report Categories

* Harassment
* Fake Profile
* Inappropriate Content
* Scam

---

## Workflow

1. Select User.
2. Choose Report Reason.
3. Add Optional Description.
4. Submit Report.

---

## Admin Actions

* Review Report
* Warn User
* Suspend User
* Permanently Ban User
* Close Report

---

## Database Tables

* user_reports
* report_categories
* moderation_actions

---

## Acceptance Criteria

* Report submitted successfully.
* User notified only if configured by the administrator.
* Report appears in the Admin Moderation Dashboard.
