# Software Requirements Specification (SRS)

# Chapter 6 - Group Chat Engine

---

# Module Overview

The Group Chat Engine enables multiple users to communicate within a shared conversation space. It supports role-based permissions, configurable group settings, media sharing, moderation tools, and future collaboration features while remaining optimized for Laravel on cPanel hosting.

---

# FR-071 - Create Group

## Purpose

Allow authenticated users to create a new group conversation.

---

## Actor

Authenticated User

---

## Priority

Critical

---

## Workflow

1. User selects **Create Group**.
2. Selects participants.
3. Enters group name.
4. Uploads optional group image.
5. Creates the group.
6. Selected users become members.

---

## Validation Rules

* Group name is required.
* Maximum group name length is configurable.
* Minimum members: 2
* Maximum members configurable by administrator.

---

## Database Tables

* groups
* group_members

---

## Acceptance Criteria

* Group created successfully.
* Members are added.
* Welcome activity appears in the chat.

---

# FR-075 - Add Members

## Purpose

Allow authorized users to invite additional members.

---

## Methods

* Share Invite Link (Optional)

---

## Business Rules

# FR-076 - Remove Members

## Purpose

Allow authorized users to remove members.

---

## Business Rules

* Removed users lose immediate access.
* Chat history visibility after removal is configurable.

---

# FR-077 - Leave Group

## Purpose

Allow members to leave voluntarily.

---

## Workflow

1. User selects **Leave Group**.
2. Confirmation displayed.
3. Membership removed.

---

## Business Rules

If the owner leaves, ownership must be transferred before exit.

---

# FR-078 - Delete Group

# Chapter Summary

This chapter defines the complete Group Chat Engine, including group creation, role-based permissions, moderation, announcements, mentions, polls, media sharing, activity logging, and configurable administration. It establishes the collaboration layer that will integrate with file sharing, voice calls, video meetings, and future workspace features.
