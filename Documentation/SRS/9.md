# Software Requirements Specification (SRS)

# Chapter 9 - Meeting Engine

---

# Module Overview

The Meeting Engine provides secure real-time collaboration for one-to-one and multi-user meetings using WebRTC. It supports instant meetings, scheduled meetings, guest access, calendar invitations, participant management, screen sharing, whiteboard integration, meeting chat, and host controls.

The Meeting Engine shall integrate seamlessly with the Chat Engine, Calendar Engine, Notification Engine, Authentication Engine, and File Sharing Engine.

Version 1 targets deployment on Laravel with cPanel hosting while remaining architecturally ready for future migration to dedicated media infrastructure if required.

---

# FR-121 - Start Instant Meeting

## Purpose

Allow authenticated users to instantly create a meeting.

---

## Actor

Authenticated User

---

## Priority

Critical

---

## Workflow

1. User clicks **New Meeting**.
2. System generates Meeting ID.
3. Meeting room created.
4. Host joins automatically.
5. Invite link generated.

---

## Acceptance Criteria

* Meeting created successfully.
* Host joins immediately.
* Invite link available.

# FR-124 - ICS Calendar Invitation

## Purpose

Generate a standards-compliant calendar invitation.

---

## Requirements

System shall generate a valid RFC5545 `.ics` file.

The invitation email shall include:

* Organizer
* Start Time
* End Time
* Time Zone
* Meeting Link
* Description
* Meeting ID
* Optional Password

---

## Business Rules

Guest-only meetings shall not generate ICS invitations.

---

## Database Tables

* meetings
* meeting_invitations

# FR-126 - Guest Mode

## Purpose

Allow guests to join without registration.

---

## Workflow

1. Guest opens invite link.
2. Enters display name.
3. Requests access.
4. Host approves (if waiting room enabled).

---

## Business Rules

Default guest session duration:

15 Minutes

Administrator configurable.

Guests cannot:

* Schedule meetings
* Access chat history outside the meeting
* View user profiles
* Access private conversations

# Chapter Summary

The Meeting Engine provides the complete collaboration foundation for Meet, including instant meetings, scheduled meetings, RFC5545 ICS calendar invitations, guest access, participant management, waiting rooms, host controls, meeting chat, screen sharing, whiteboard integration, lifecycle management, configurable administration, and future-ready extensibility. It is designed to operate efficiently on Laravel with cPanel hosting while keeping the architecture flexible for future scaling.
