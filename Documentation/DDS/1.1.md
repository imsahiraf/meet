# 1. Module Overview

The Authentication & User Core module is responsible for identity management, authentication, authorization support, user profile initialization, device tracking, session management, and user preferences.

This module serves as the foundation for every other module in the Meet platform.

All other modules reference the `users` table through foreign keys.

---

## Purpose

Stores the primary identity and authentication information for every registered user.

The table represents one user account within the Meet platform.

Every authenticated feature in the system depends upon this table.

## Business Rules

1.

Email must always be unique.

---

2.

Phone number must always be unique.

---

3.

Password shall only contain a secure password hash.

---

4.

Email verification is mandatory before using communication features.

---

5.

Soft Delete shall be used instead of immediate permanent deletion.

---

6.

Users cannot authenticate when account status is:

```text
inactive

suspended
```

---

7.

Deleted users remain available for reporting until retention policy removes them permanently.

# TABLE 2

# email_otps

---

## Purpose

Stores One-Time Passwords (OTP) generated for email verification, password reset initiation, email changes, and future authentication flows.

Each OTP is temporary, single-use, and expires automatically based on system configuration.

## Business Rules

* One OTP is valid for one verification cycle only.
* OTP expiry duration shall be configurable from the Admin Panel.
* Expired OTPs shall not be accepted.
* Successfully verified OTPs cannot be reused.
* Maximum verification attempts shall be configurable.
* Expired records shall be removed automatically by scheduled cleanup jobs.

---

## Validation Rules

* Email is required.
* OTP is generated by the system.
* Expiration time is mandatory.
* Verification is allowed only while the OTP is in the `pending` state.
