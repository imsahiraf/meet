# TABLE 1

# uploads

## Purpose

Stores upload sessions before files are fully processed.

### Columns

* id
* uuid
* user_id
* upload_token
* total_size
* uploaded_size
* total_chunks
* uploaded_chunks
* status
* expires_at
* created_at
* updated_at

### Business Rules

* Supports resumable uploads.
* Automatically expires incomplete uploads.
* Chunk uploads are merged after successful completion.

---

# TABLE 2

# upload_chunks

## Purpose

Tracks uploaded chunks for large file uploads.

### Columns

* id
* uuid
* upload_id
* chunk_number
* chunk_size
* checksum
* uploaded_at

### Business Rules

* Duplicate chunks are ignored.
* Missing chunks prevent file assembly.
* Cleanup handled by Scheduler.

# DDS-5 Summary

This module establishes the database foundation for media management, resumable uploads, One View media, calendar scheduling, ICS-ready events, reminders, RSVP tracking, notifications, broadcasts, and configurable storage. Together with the previous DDS modules, it enables reliable file handling, scheduling, and communication workflows for the Meet platform while remaining compatible with Laravel, MySQL, and cPanel deployment.
