# TABLE 3

# password_reset_tokens

---

## Purpose

Stores secure password reset requests initiated by users.

Each reset token is single-use, time-limited, and invalidated immediately after successful password reset.

---

## Table Name

```text
password_reset_tokens
```

---

## Primary Key

| Column | Type                           |
| ------ | ------------------------------ |
| id     | BIGINT UNSIGNED AUTO_INCREMENT |

---

## Columns

| Column     | Data Type       | Length | Null | Default           | Index   |
| ---------- | --------------- | ------ | ---- | ----------------- | ------- |
| id         | BIGINT UNSIGNED | -      | No   | Auto Increment    | Primary |
| uuid       | CHAR            | 36     | No   | Generated         | Unique  |
| user_id    | BIGINT UNSIGNED | -      | No   | -                 | Index   |
| email      | VARCHAR         | 255    | No   | -                 | Index   |
| token      | VARCHAR         | 255    | No   | -                 | Unique  |
| expires_at | TIMESTAMP       | -      | No   | -                 | Index   |
| used_at    | TIMESTAMP       | -      | Yes  | NULL              | -       |
| status     | ENUM            | -      | No   | active            | Index   |
| created_at | TIMESTAMP       | -      | No   | CURRENT_TIMESTAMP | -       |
| updated_at | TIMESTAMP       | -      | No   | CURRENT_TIMESTAMP | -       |

---

## Status Values

```text
active

used

expired
```

---

## Foreign Keys

```text
user_id

↓

users.id
```

---

## Business Rules

* One active reset token per user.
* Tokens expire automatically.
* Used tokens cannot be reused.
* Password reset duration shall be configurable.
* Password must be updated only after successful token validation.

---

## Relationships

User

↓

Many Password Reset Requests

---

## Laravel Model

```text
App\Models\PasswordResetToken
```

---

## Migration

```text
create_password_reset_tokens_table
```

---

## Audit Requirements

Log

* Reset Requested
* Reset Completed
* Reset Failed
* Token Expired

# TABLE 4

# email_verifications

---

## Purpose

Maintains a history of email verification events for auditing and security.

Unlike the users table, this table preserves verification history.

---

## Table Name

```text
email_verifications
```

---

## Columns

| Column            | Data Type       | Length | Null | Default           | Index   |
| ----------------- | --------------- | ------ | ---- | ----------------- | ------- |
| id                | BIGINT UNSIGNED | -      | No   | Auto Increment    | Primary |
| uuid              | CHAR            | 36     | No   | Generated         | Unique  |
| user_id           | BIGINT UNSIGNED | -      | No   | -                 | Index   |
| email             | VARCHAR         | 255    | No   | -                 | Index   |
| verification_type | ENUM            | -      | No   | registration      | Index   |
| verified_at       | TIMESTAMP       | -      | No   | CURRENT_TIMESTAMP | Index   |
| verified_ip       | VARCHAR         | 45     | Yes  | NULL              | -       |
| user_agent        | TEXT            | -      | Yes  | NULL              | -       |
| created_at        | TIMESTAMP       | -      | No   | CURRENT_TIMESTAMP | -       |
| updated_at        | TIMESTAMP       | -      | No   | CURRENT_TIMESTAMP | -       |

---

## Verification Types

```text
registration

email_change

administrator

future_manual
```

---

## Foreign Keys

```text
user_id

↓

users.id
```

---

## Business Rules

* Every successful verification creates one history record.
* Verification history shall never be edited.
* Records are retained according to the configured retention policy.

---

## Relationships

User

↓

Many Email Verification Records

---

## Laravel Model

```text
App\Models\EmailVerification
```

---

## Migration

```text
create_email_verifications_table
```

---

## Soft Deletes

Not Required

---

## Audit Requirements

Log

* Email Verified
* Verification Method
* Verification Device
* Verification IP

# TABLE 5

# user_sessions

---

## Purpose

Stores active and historical login sessions.

Supports account security, session management, forced logout, and device tracking.

---

## Table Name

```text
user_sessions
```

---

## Columns

| Column           | Data Type       | Length | Null | Default           | Index   |
| ---------------- | --------------- | ------ | ---- | ----------------- | ------- |
| id               | BIGINT UNSIGNED | -      | No   | Auto Increment    | Primary |
| uuid             | CHAR            | 36     | No   | Generated         | Unique  |
| user_id          | BIGINT UNSIGNED | -      | No   | -                 | Index   |
| session_id       | VARCHAR         | 255    | No   | -                 | Unique  |
| ip_address       | VARCHAR         | 45     | Yes  | NULL              | Index   |
| device_name      | VARCHAR         | 150    | Yes  | NULL              | -       |
| browser          | VARCHAR         | 100    | Yes  | NULL              | -       |
| operating_system | VARCHAR         | 100    | Yes  | NULL              | -       |
| platform         | VARCHAR         | 50     | Yes  | NULL              | -       |
| login_at         | TIMESTAMP       | -      | No   | CURRENT_TIMESTAMP | Index   |
| last_activity_at | TIMESTAMP       | -      | Yes  | NULL              | Index   |
| logout_at        | TIMESTAMP       | -      | Yes  | NULL              | -       |
| status           | ENUM            | -      | No   | active            | Index   |
| created_at       | TIMESTAMP       | -      | No   | CURRENT_TIMESTAMP | -       |
| updated_at       | TIMESTAMP       | -      | No   | CURRENT_TIMESTAMP | -       |

---

## Status Values

```text
active

expired

logged_out

terminated
```

---

## Foreign Keys

```text
user_id

↓

users.id
```

---

## Business Rules

* A user may have multiple active sessions if allowed by system settings.
* Administrators may terminate any active session.
* Users may view and revoke their own active sessions.
* Session timeout shall be configurable.

---

## Relationships

User

↓

Many Sessions

---

## Indexes

* PRIMARY KEY (`id`)
* UNIQUE (`uuid`)
* UNIQUE (`session_id`)
* INDEX (`user_id`)
* INDEX (`status`)
* INDEX (`login_at`)
* INDEX (`last_activity_at`)

---

## Laravel Model

```text
App\Models\UserSession
```

---

## Migration

```text
create_user_sessions_table
```

---

* Login
* Logout
* Session Expired
* Session Terminated
* Device Change
