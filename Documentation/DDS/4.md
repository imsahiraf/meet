# Database Design Specification (DDS)

## DDS - Part 4

## Voice Calls, Video Calls, Meetings & Whiteboard Module

**Version:** 1.0

**Database:** MySQL 8+

**Framework:** Laravel 12

**ORM:** Laravel Eloquent

---

# Module Overview

This module manages:

* One-to-One Voice Calls
* One-to-One Video Calls
* WebRTC Signaling
* ICE Candidate Exchange
* Meeting Creation
* Meeting Participants
* Guest Access
* Waiting Room
* Screen Sharing
* Whiteboard
* Meeting Chat Integration
* Meeting Logs
* Meeting Reports

Media streams are transmitted using **WebRTC Peer-to-Peer**, while Laravel stores only signaling, metadata, permissions, and history.

# TABLE 1

# calls

---

## Purpose

Stores metadata for every voice and video call.

---

## Columns

* id
* uuid
* caller_id
* receiver_id
* conversation_id NULL
* call_type (voice, video)
* call_status (ringing, accepted, rejected, missed, ended)
* started_at
* answered_at NULL
* ended_at NULL
* duration_seconds
* created_at
* updated_at

---

## Business Rules

* One active call between the same participants at a time.
* Media is not stored in the database.
* Duration is calculated when the call ends.

# DDS-4 Summary

This module provides the relational foundation for voice calls, video calls, meetings, guest access, waiting rooms, WebRTC signaling, whiteboards, and meeting analytics. It is designed to work with Laravel, MySQL, AJAX polling, and WebRTC, while remaining fully deployable on cPanel hosting without requiring Node.js.
