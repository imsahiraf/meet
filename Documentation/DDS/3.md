## DDS - Part 3

## Groups & Community Module

**Version:** 1.0

**Database:** MySQL 8+

**Framework:** Laravel 12

**ORM:** Laravel Eloquent

---

# Module Overview

The Groups & Community module manages group creation, membership, roles, permissions, invitations, join requests, announcements, polls, events, and moderation.

This module integrates with:

* Authentication
* Contacts
* Chat
* Media & Files
* Notifications
* Analytics
* Archive
* Administration

Group chat messages continue to use the **conversations** and **messages** tables defined in DDS-2.

# TABLE 1

# groups

---

## Purpose

Stores the primary information for every group.

Each group is linked to a conversation used for messaging.

---

## Columns

| Column            | Type                          |
| ----------------- | ----------------------------- |
| id                | BIGINT UNSIGNED               |
| uuid              | CHAR(36)                      |
| conversation_id   | BIGINT UNSIGNED               |
| owner_id          | BIGINT UNSIGNED               |
| name              | VARCHAR(150)                  |
| description       | TEXT NULL                     |
| avatar            | VARCHAR(255) NULL             |
| invite_code       | VARCHAR(50) NULL              |
| member_limit      | INT DEFAULT 512               |
| approval_required | BOOLEAN DEFAULT false         |
| status            | ENUM(active,archived,deleted) |
| created_at        | TIMESTAMP                     |
| updated_at        | TIMESTAMP                     |
| deleted_at        | TIMESTAMP NULL                |

---

## Business Rules

* One conversation belongs to one group.
* Group names are editable.
* Member limits are configurable.
* Soft delete is enabled.

# DDS-3 Summary

The Groups & Community module establishes the database structure required for group management, member administration, permissions, announcements, polls, invitations, events, media indexing, and audit logging. Together with DDS-2, it provides the complete relational foundation for group communication within the Meet platform.
