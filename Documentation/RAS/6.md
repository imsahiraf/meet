# Meet v1.0

# REST API Specification (RAS)

## RAS - Part 6

## Administration APIs

**Version:** 1.0

**Framework:** Laravel 12

**Authentication:** Laravel Sanctum (Bearer Token)

**Authorization:** Role-Based Access Control (RBAC)

**Base URL**

```text
/api/v1/admin
```

---

# Module Overview

This module defines all administrator APIs used to manage the Meet platform.

Every endpoint in this module requires:

* Authenticated Administrator
* Appropriate Permission
* Audit Logging

Every administrative action shall be recorded in Audit Logs.

# Security Rules

* Administrator authentication is mandatory.
* RBAC permissions are validated before every action.
* All administrative actions are written to the audit log.
* Sensitive configuration values (such as SMTP passwords) are encrypted before storage.
* Destructive actions require explicit confirmation in the client application.

# RAS-6 Summary

This module defines the REST APIs for platform administration, including user management, RBAC, branding, SMTP configuration, feature flags, application settings, queue management, scheduler controls, storage management, backup and restore, system health, and operational logs.
