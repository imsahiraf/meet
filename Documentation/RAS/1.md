# API 1

## Register User

Endpoint

```
POST /auth/register
```

Authentication

```
No
```

Request

```json
{
    "full_name":"John Doe",
    "email":"john@example.com",
    "phone":"+919999999999",
    "password":"********",
    "password_confirmation":"********"
}
```

Validation

* Full name required
* Email unique
* Phone unique
* Password confirmation required

Success

```json
{
    "success":true,
    "message":"Registration successful. Please verify your email."
}
```

Possible Errors

* Email already exists
* Phone already exists
* Invalid input
* Validation failed

Business Rules

* Create user account.
* Generate email OTP.
* Send verification email.
* Do not allow login until email verification is complete.

# API 4

## Login

Endpoint

```
POST /auth/login
```

Authentication

```
No
```

Request

```json
{
    "login":"john@example.com",
    "password":"********"
}
```

`login` may contain the user's email or phone number.

Success

```json
{
    "success":true,
    "message":"Login successful.",
    "data":{
        "token":"Bearer Token",
        "user":{}
    }
}
```

Business Rules

* Authenticate using email or phone.
* Reject users with unverified email.
* Create a user session.
* Record login attempt.
* Return Sanctum token.

Possible Errors

* Invalid credentials
* Account suspended
* Email not verified
* Too many login attempts

The Authentication module defines the core identity APIs for registration, email verification, login, logout, password recovery, session management, and account security. All protected endpoints use Laravel Sanctum bearer authentication and follow the standard request/response format defined in this specification.
