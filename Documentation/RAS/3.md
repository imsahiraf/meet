# Meet v1.0

# REST API Specification (RAS)

## RAS - Part 3

## Groups APIs

**Version:** 1.0

**Framework:** Laravel 12

**Authentication:** Laravel Sanctum (Bearer Token)

**Base URL**

```text
/api/v1
```

---

# Module Overview

This module defines all APIs related to group creation, member management, administration, invitations, announcements, polls, events, permissions, moderation, and media.

All endpoints require authentication.

---

# GROUP MANAGEMENT

---

## API 1

### Create Group

**POST**

```text
/groups
```

Request

* group_name
* description
* members[]
* avatar (optional)

Business Rules

* Creator becomes Group Owner.
* Conversation is created automatically.
* Initial members receive notifications.

---

## API 2

### Group List

**GET**

```text
/groups
```

Returns

* Group Name
* Avatar
* Member Count
* Last Activity
* Last Message

Supports

* Pagination
* Search

---

## API 3

### Group Details

**GET**

## API 4

## API 5

# Security Rules

* Every endpoint requires authentication.
* Group permissions are validated before execution.
* Owner-only actions cannot be performed by other roles.
* Rate limiting applies to invitation and join-request endpoints.

---

# RAS-3 Summary

This module defines the complete REST API for group lifecycle management, including creation, membership, roles, permissions, invitations, announcements, polls, events, media, and administrative actions. It provides the API contract required for implementing collaborative group functionality within the Meet platform.
