# Meet v1.0

# REST API Specification (RAS)

## RAS - Part 4

## Voice Calls, Video Calls, Meetings & Whiteboard APIs

**Version:** 1.0

**Framework:** Laravel 12

**Authentication:** Laravel Sanctum (Bearer Token)

**Base URL**

```text
/api/v1
```

---

# Module Overview

This module defines APIs for:

* One-to-One Voice Calls
* One-to-One Video Calls
* WebRTC Signaling
* ICE Candidate Exchange
* Meeting Scheduling
* Instant Meetings
* Guest Join
* Waiting Room
* Screen Sharing
* Whiteboard
* Meeting Chat
* Meeting Reports

Media streams are transmitted directly using WebRTC. The REST APIs are responsible for signaling, meeting management, permissions, metadata, and history.

---

# VOICE & VIDEO CALL APIs

---

## API 1

### Start Voice Call

**POST**

```text
/calls/voice/start
```

Request

* receiver_id
* conversation_id (optional)

Business Rules

* Creates a call session.
* Generates a unique call identifier.
* Notifies the receiver.

---

## API 2

### Start Video Call

**POST**

```text
/calls/video/start
```

Request

* receiver_id
* conversation_id (optional)

Business Rules

* Creates a video call session.
* Camera permission is handled by the client.

---

# Security Rules

* Every protected endpoint requires authentication.
* Meeting permissions are validated before each operation.
* Hosts and Co-Hosts have elevated meeting controls.
* Guest access follows configured meeting policies.
* All signaling requests are validated against the active call session.

# RAS-4 Summary

This module defines the REST APIs required for voice calls, video calls, WebRTC signaling, meetings, guest access, waiting rooms, screen sharing, whiteboards, meeting chat, and reporting. It provides the complete API contract for real-time collaboration features within the Meet platform.
