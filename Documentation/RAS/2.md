# Meet v1.0

# REST API Specification (RAS)

## RAS - Part 2

## User, Contacts & Chat APIs

**Version:** 1.0

**Framework:** Laravel 12

**Authentication:** Laravel Sanctum (Bearer Token)

**Base URL**

```text
/api/v1
```

---

# Module Overview

This module defines APIs for:

* User Profile
* User Preferences
* Privacy Settings
* User Presence
* Device Management
* Contact Management
* User Search
* Conversations
* Messaging
* Reactions
* Replies
* Forwarding
* Read Receipts
* Typing Status
* Draft Messages
* Chat Settings

All APIs require authentication unless explicitly marked as public.

---

# USER APIs

---

## API 1

### Get My Profile

**GET**

```text
/users/profile
```

Authentication

Required

Purpose

Returns the authenticated user's complete profile.

Response

* Basic Information
* Profile Information
* Preferences
* Privacy Settings
* Presence Status

---

## API 2

### Update Profile

**PUT**

```text
/users/profile
```

Request

* Full Name
* Display Name
* Bio
* Date of Birth
* Website
* Avatar
* Cover Photo

Business Rules

* Avatar upload uses the Media module.
* Empty fields remain optional.

## API 4


## API 5

### Get Active Devices

**GET**

```text
/users/devices
```

Returns

* Device Name

---

## API 6

### Remove Device

**DELETE**


## API 7

### Search Users

**GET**

```text
/users/search
```

This section defines the REST APIs for user management, contacts, conversations, and messaging. It establishes the endpoints required for profile management, contact workflows, private messaging, reactions, replies, typing indicators, drafts, chat settings, and related events and background jobs.
