# FILE UPLOAD APIs

---

## API 1

### Initialize Upload

**POST**

```text
/files/upload/init
```

Purpose

Creates an upload session for resumable uploads.

Request

* file_name
* file_size
* mime_type
* total_chunks

Response

* upload_id
* upload_token

---

## API 2

### Upload Chunk

**POST**

```text
/files/upload/chunk
```

Content Type

```text
multipart/form-data
```

Request

* upload_id
* chunk_number
* chunk_file

Business Rules

* Supports interrupted uploads.
* Duplicate chunks are ignored.
* Checksum validation is recommended.

---

## API 3

### Complete Upload

**POST**

```text
/files/upload/complete
```

Business Rules

* Merge uploaded chunks.
* Create media record.
* Generate thumbnail where applicable.
* Trigger background processing.

---

## API 4

### Cancel Upload

**DELETE**

```text
/files/upload/{uploadId}
```

---

## API 5

### Upload Progress

**GET**

```text
/files/upload/{uploadId}/progress
```

Returns

* Uploaded Chunks
* Remaining Chunks
* Percentage Complete

# ONE VIEW APIs

---

## API 11

### Send One View File

**POST**

```text
/files/one-view
```

Request

* receiver_id
* media_id

Business Rules

* Accessible only once for normal users.
* Automatically removed after viewing according to configured policy.

---

## API 12

### Open One View File

**GET**

```text
/files/one-view/{fileId}
```

Business Rules

* Marks file as viewed.
* Triggers deletion workflow for standard users.
* Users with configured administrative privileges follow the platform's One View policy.

# Security Rules

* Authentication is required for all endpoints.
* File access is validated before download or sharing.
* Chunk uploads require a valid upload session.
* Calendar invitations are accessible only to authorized participants.
* Notification preferences apply to future deliveries.

# RAS-5 Summary

This module defines the REST APIs for resumable file uploads, media management, One View files, calendar events, ICS generation, reminders, RSVP, notifications, and broadcasts. It establishes the API contract for file handling and user communication features across the Meet platform.
